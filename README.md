# Yashas's Portfolio

This repository contains the source code for [iyashasgowda.com](https://iyashasgowda.com)

## Info

The portfolio has been migrated to a React + Vite app while preserving the original design, sections, and asset structure.

## Local development

```bash
export PATH=/home/iyashasgowda/.local/node/bin:$PATH
npm install
npm run dev
```

## Production build

```bash
export PATH=/home/iyashasgowda/.local/node/bin:$PATH
npm run build
```
